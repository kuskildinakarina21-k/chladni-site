# Фигуры Хладни · Аудио-реактивная анимация

Интерактивный сайт с генеративной анимацией фигур Хладни, реагирующей на звук с микрофона.

## Как это работает

- Использует **Three.js** для 3D-рендеринга
- Анализирует звук через **Web Audio API**
- Генерирует узоры Хладни в реальном времени

## Как использовать

1. Откройте сайт
2. Нажмите "Активировать звук"
3. Разрешите доступ к микрофону
4. Говорите или включите музыку

## Технологии

- Three.js
- Web Audio API
- GitHub Pages
